# Random Quote Generator

A modern and responsive Random Quote Generator built using HTML, CSS, and JavaScript.

## Features

* Displays random quotes on page load
* Generates a new quote with a single click
* Contains 200+ inspirational, motivational, devotional, emotional, success, and life quotes
* Shows verified author names
* Copy quote functionality
* Auto-refreshes quotes every 30 seconds
* Fully responsive design
* No external APIs required
* Fast and lightweight

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Project Purpose

This project was developed to practice JavaScript DOM manipulation, event handling, randomization, user interaction, and responsive web design while creating a useful and inspiring application.
